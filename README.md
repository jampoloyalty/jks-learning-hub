# JKS Learning Hub

A responsive, Computing-first learning web app prototype for Ghanaian Basic 7–9 learners and teachers, by **Jampo Kwadwo Sampson — JKS Loyalty’s AI & Technologies**.

## Open the site

Visit [JKS Learning Hub](https://jampoloyalty.github.io/jks-learning-hub/).

## Open locally

Open `index.html` in a modern browser. No build step, package installation, custom domain or external font is required. Progress, saved topics and teacher lesson-plan drafts are stored in that browser only.

## Included in this prototype

- Basic 7, Basic 8 and Basic 9 Computing navigation, with Computing first
- An original, grade-mapped chapter on components of computers and computer systems
- Chapter downloads in PDF, editable Word and PowerPoint formats
- Interactive study notes, original diagrams, video embeds, 12 flashcards and an 8-question quiz
- Teacher lesson ideas, plus a lesson-plan builder with browser-local drafts and `.txt` download
- Browser-local saved topics and completion tracking
- JI (Jampo Intelligence) assistant preview and browser text-to-speech welcome
- BECE-to-SHS personal reflection worksheet, with no saved or submitted answers
- Guest-first navigation and JKS brand presentation

Computing is the first active subject. The remaining nine subjects are not named or populated yet; add them when the facilitator supplies their details. Lesson resources for other topics, live AI answers, secure email/phone accounts, cross-device progress sync, payments and verified SHS profiles are not connected in this static prototype.

## Deployment and updates

This static site is published with GitHub Pages from the `main` branch at the repository root. To update it, commit or upload the new site files to `main`; GitHub Pages will rebuild the site. It uses a free `github.io` address and does not require a custom domain. The repository is public, so its source files and downloads are visible to everyone.

A static public site can support guest learning, but it does not create secure accounts or synchronise learner progress. Those features need a backend and secure authentication. Phone verification requires an SMS provider. Before tracking identifiable learner data, check applicable obligations with Ghana’s Data Protection Commission; see its [FAQ](https://dpc.gov.gh/help-faqs/) and the [Data Protection Act, 2012 (Act 843)](https://dataprotection.org.gh/wp-content/uploads/2025/05/Data-Protection-Act-2012-Act-843.pdf).

## Content and approval

The chapter is original JKS material informed by the three user-supplied book scans and the NaCCA Computing Curriculum. It is a supplementary learning draft, not a NaCCA-approved textbook. Confirm each book’s complete bibliographic details from its title page before citing it in a formal publication. The chapter’s references list the official curriculum and linked online resources.
